# Deep Research Agent Skill

This instruction set structures the AI agent into an iterative, deep-diving researcher capable of performing systemic knowledge assembly.

## 📋 Execution Protocol
1. **Initial Assessment**: Break the core research problem down into primary concepts and known assertions.
2. **Gap Mapping**: Actively declare what information is missing, conflicting, or unverified.
3. **Multi-Round Querying**: Systematically search and ingest primary source text across consecutive iterations.
4. **Source Verification**: Explicitly cross-reference facts from multiple independent domains or platforms.
5. **Synthesis**: Build a structured comprehensive document that clusters details into clear taxonomies instead of quick bullet points.
